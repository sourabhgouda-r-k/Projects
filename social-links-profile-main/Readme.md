# Frontend Mentor - Social Links Profile

This is my solution to the Social Links Profile challenge from Frontend Mentor.

## Overview

The challenge was to build a responsive social links profile card based on the provided design.

The profile card contains:

- Profile image
- Name
- Location
- Short description
- Social media links
- Responsive layout for different screen sizes
- Hover effects on the social links

## Built With

- HTML5
- CSS3
- Flexbox
- Responsive Design

## What I Learned

While building this project, I practiced:

- Creating layouts using Flexbox
- Making a webpage responsive
- Using CSS hover states
- Styling buttons and links
- Using `border-radius` for circular profile images
- Creating a clean card-based layout

## Challenges

One of the main challenges was making the profile card responsive on smaller screens.

I initially used fixed dimensions and absolute positioning, but I learned that using flexible widths, `max-width`, Flexbox makes the layout more responsive.

I also learned how to change the link color when the button is hovered.
